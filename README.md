# ilac_hatirlatici_uygulamasi

İlaç/tedavi hatırlatıcı planlayıcısını `python3 ilac_hatirlatici.py` komutuyla
çalıştırabilirsiniz. Menüden hatırlatıcı ekleyebilir, listeleyebilir,
düzenleyebilir veya silebilirsiniz. Düzenleme sırasında boş bırakılan alanlar
mevcut değerlerini korur; silme işlemi ayrıca onay ister.
